# Arti-Fex

Clickable prototype of Arti-Fex, a design concept for an online store of AI art prints.

Live: https://irynachelombitko.github.io/arti-fex/

You can browse 18 prints in six collections, search, filter and sort the shop, save prints, pick a size and a frame, see a print to scale on a wall, fill a cart, walk through a demo checkout and write a commission brief. Nothing is charged, sent or shipped: everything you enter stays in your own browser.

Design: Iryna Chelombitko, UX/UI designer. Case study on Behance: https://www.behance.net/Iryna_chelombitko

Plain HTML, CSS and JavaScript in one file, no build step.
